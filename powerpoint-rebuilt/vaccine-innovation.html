The charts
weren't the story.
The contradiction was.

This PowerPoint transformation reframes a 40-slide vaccine-innovation discussion into a focused 10-slide narrative.

The source contained strong data on unmet need, pipeline growth, sales, development economics, technical difficulty and commercial pressure.

Instead of treating each chart as a separate finding, the redesign builds one visual system around the innovation engine:

  • 01how it grows,
  • 02where it stalls,
  • 03and what needs to change.

The result is a presentation that behaves like a diagnosis, not a report summary.

One visual system.
Ten slides.

The strongest design decision in the project: every finding is told as a state of the same innovation engine. The cover sets it running, the middle of the deck strains it, and the close sets it running again.

What changed

Five decisions, each one a step from report to argument.

  1. DATAMany charts→one argument
  2. STRUCTUREMultiple findings→one diagnosis
  3. VISUAL LANGUAGECharts and frameworks→one recurring engine metaphor
  4. MOTIONStatic→progressive explanation
  5. FORMATLong corporate presentation→10-slide editable PowerPoint story

Built in
PowerPoint.

Close details from the finished .pptx. Every diagram, chart and layout on this page is a native PowerPoint object that can be opened, edited and presented.

01 · MASTER

Three named layouts with kicker, title, source and page placeholders. Theme colours and fonts live in the theme, so the deck restyles in one place.

02 · MORPH

Sixteen frames for ten slides. Objects share Morph names across frames, so the pinches retract, queues dissolve and the output grows, instead of one slide replacing another.
